# Mox IP：白色状态助手

Mox 是 `dive into X` 的专属白色状态助手，名字来自 Module + X：它通过右肩模块连接工具，用 X 作为小而明确的品牌标记。

这份文件是 `learn-pi-agent` 教程配图的角色唯一设定。使用 `mox-illustrations` 时，必须用本角色替换 Skill 默认的“小黑”；保留 Skill 的构图、留白和手绘方法，但不要绘制小黑本体。

## 核心形象

- 一只没有具体物种和性别的白色小机器人；
- 身体圆润、略带不对称，白色占主体约 80%；
- 黑色椭圆面部，两个白色眼睛；
- 两只短黑色手、两只黑脚；
- 头顶一盏小橙色指示灯；
- 右肩连接一个紧凑的黑色功能模块，模块上有很小的 X 徽记；
- 腹部保持干净，不放大 Logo 或复杂屏幕；
- X 只是品牌标记，不构成身体轮廓。

## 性格

安静、认真、好奇、可靠。它不是全知全能的机器人，而是遇到未知后愿意继续深入的学习伙伴。可以有轻微荒诞感，但不要卖萌、不要儿童卡通化。

## 视觉约束

- 纯白背景、黑色手绘线稿、大量留白；
- 白色主体，黑色轮廓和结构，橙色只用于指示灯、状态信号和少量 X 标记；
- 不使用海洋、潜水、鱼、鳍、浮标、贝壳等元素；
- 不使用 Codex 的云头机器人或 Claude Code 的橙色像素生物；
- 不把画面做成 PPT、UI 截图或密集信息图；
- 角色必须参与画面的核心动作，不能只站在旁边装饰。

## 状态语言

| 状态 | 肩部模块 | 顶部指示灯 | 动作表现 |
| --- | --- | --- | --- |
| 待机 | 关闭，X 暗 | 低亮 | 双手下垂 |
| 收到问题 | 唤醒 | 明亮橙色 | 轻微歪头 |
| 思考 / 上下文 | 打开信息窗口 | 脉冲 | 关注信息块 |
| 调用工具 | 伸出短机械臂 | 橙色信号线 | 连接工具对象 |
| 读取结果 | 托住信息卡 | 柔和脉冲 | 专注观察 |
| 执行中 | 保持展开 | 稳定亮起 | 手臂动作加快 |
| 等待输入 | 展开小托盘 | 柔和橙色 | 向用户摊手 |
| 完成 | X 发光 | 明亮橙色 | 双手抬起 |
| 受阻 | 收回或折叠 | 闪烁 | 双手收拢、疑惑 |

## 调用时的覆盖语句

使用 `mox-illustrations` 时，在提示词中加入：

> 使用 `references/mox-ip.md` 中的 Mox 作为唯一主角。不要使用 Skill 默认的小黑；保留白底、手绘线条、留白和怪诞隐喻方法。右肩模块和顶部橙灯必须参与本图表达的核心动作。

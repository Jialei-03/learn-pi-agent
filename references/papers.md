# 论文与研究背景

论文帮助理解方法和局限；Pi 是否实现某种机制，要回到代码核对，不能仅因行为相似就推断直接继承某篇论文。

| 原文 | 研究主题 | 与课程的联系及边界 |
| --- | --- | --- |
| [ReAct](https://arxiv.org/abs/2210.03629) | 推理与外部行动交替 | 工具循环的背景，不替代 Pi 真实调度说明 |
| [Toolformer](https://arxiv.org/abs/2302.04761) | 模型学习使用工具 | 工具使用的训练研究，不等于宿主执行器实现 |
| [Retrieval-Augmented Generation](https://arxiv.org/abs/2005.11401) | 检索外部材料辅助生成 | 理解检索和上下文，不能等同会话持久化 |
| [Self-Refine](https://arxiv.org/abs/2303.17651) | 自反馈与迭代改进 | 反馈循环的参考，应用仍需评价和停止条件 |
| [Reflexion](https://arxiv.org/abs/2303.11366) | 用语言反馈改善后续任务 | 反思与跨尝试状态的背景 |
| [Tree of Thoughts](https://arxiv.org/abs/2305.10601) | 多候选思路搜索 | 需要搜索和评价机制，普通工具循环不自动具备 |
| [AgentDojo](https://arxiv.org/abs/2406.13352) | Agent 效用和提示注入的动态评测 | 安全测试应同时检查动作与任务效果 |

本课程不引用这些研究作为当前模型、产品或协议的最新性能排名。研究结论需要放回各自任务、模型、预算和评测设置理解。

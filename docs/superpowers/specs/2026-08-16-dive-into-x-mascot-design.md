# dive into X 吉祥物探索板设计

## 目标

为 `dive into X` 设计一组原创、可小尺寸识别、适合后续制作状态动画的宽泛数字伙伴候选。`dive` 表示深入知识与未知，不绑定海洋或具体物种。X 只作为品牌标记，不决定角色主体。当前探索以白色小机器人为主体，先比较三个轮廓方向。

## 角色方向

### 三个白色机器人候选

- 版本 A：圆润豆形机器人，白色软壳、黑色面部和关节、橙色状态灯，亲切而有记忆点；
- 版本 B：小型方形工作机器人，白色模块化外壳、黑色边角和表情、橙色肩部或胸口点缀，可靠而灵活；
- 版本 C：轻量悬浮机器人，白色胶囊身体、黑色环形结构、橙色信号条或小配件，适合表现状态变化；
- 三个版本都保留一个很小的 X 徽记，不把 X 做成身体轮廓；
- 后续状态统一包含：待机、思考、执行、完成、等待输入、受阻。

## 视觉约束

- 参考低细节像素宠物的清晰轮廓，但不复制 Claude Code 或 Codex 的具体形状；
- 使用简洁、有限的颜色和厚实形状，保证头像、教程插图和小动画中的可读性；
- X 是小型品牌徽记，流线表示信息流、思考轨迹或动作残影，不表现海浪；
- 白色为主体，黑色用于轮廓、关节和表情，橙色作为少量识别点；
- 机器人应保持原创，不复制 Codex 的云头机器人或 Claude Code 的像素生物；
- 不使用鳍、鱼尾、浮标、贝壳、气泡、珊瑚或潜水设备等海洋专属元素；
- 探索板为三列角色方案，不加入复杂场景、品牌文字或最终 Logo；
- 角色应能与现有 X / 波纹品牌语言建立联系，但吉祥物与 Logo 保持独立。

## 本轮交付

一张横向角色探索板：三列分别展示三个白色机器人候选。用户选定方向后，再制作单角色设定图、透明背景资产和教程使用版本。

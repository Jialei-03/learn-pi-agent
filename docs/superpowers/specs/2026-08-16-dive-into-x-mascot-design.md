# dive into X 吉祥物探索板设计

## 目标

为 `dive into X` 设计一组原创、可小尺寸识别、适合后续制作状态动画的宽泛数字伙伴候选。`dive` 表示深入知识与未知，不绑定海洋或具体物种。第一轮不定稿，只用于比较两个性格方向。

## 角色方向

### B：机灵伙伴

- 小型抽象 X 生物，带有 X 形结构或面部标记；
- 动作前倾、好奇、略带调皮；
- 珊瑚橙主体，石墨色结构，少量青色高光；
- 状态：待机、好奇、执行、完成、等待输入、受阻。

### C：可靠助手

- 圆润的通用数字伙伴；
- 轮廓稳定对称，表达沉稳、友好、可靠；
- 深蓝主体、青色面部、米白细节，珊瑚色作为状态提示；
- 状态：待机、思考、执行、完成、等待输入、受阻。

## 视觉约束

- 参考低细节像素宠物的清晰轮廓，但不复制 Claude Code 或 Codex 的具体形状；
- 使用简洁、有限的颜色和厚实形状，保证头像、教程插图和小动画中的可读性；
- X 是结构记号，流线表示信息流、思考轨迹或动作残影，不表现海浪；
- 不使用鳍、鱼尾、浮标、贝壳、气泡、珊瑚或潜水设备等海洋专属元素；
- 探索板为两行六状态，不加入复杂场景、品牌文字或最终 Logo；
- 角色应能与现有 X / 波纹品牌语言建立联系，但吉祥物与 Logo 保持独立。

## 本轮交付

一张横向角色探索板：上排 B、下排 C，每个角色展示六种状态。用户选定方向后，再制作单角色设定图、透明背景资产和教程使用版本。

# Pi Agent 源码学习路线

课程目标是从一次真实请求看清整个系统，并能够进入关键机制的具体实现。先走通主路径，再沿消息、工具、状态和扩展逐层深入。

## 一条请求经过什么

```text
CLI / SDK → AgentSession → Agent → Agent Loop → Provider → 模型
                                  ↓                 ↑
                              工具执行 → 结果写回
                    事件、会话记录与界面贯穿全过程
```

这是本地 Coding Agent 的阅读主干，省略模式和异常分支。Durable 是另一条以提交和任务恢复为中心的运行路径，后半程单独展开。

## 推荐顺序

1. **建立主干**：第 1～4 章，理解普通输入、消息转换、循环和工具执行。先理解成功路径，再读错误、中止、截断和队列。
2. **理解信息与能力**：第 5～9 章，研究系统提示、Context、Session、压缩、MCP、Skill 和 Extension 的实际接入点。
3. **把 Agent 放进应用**：第 10～14 章，研究 Workflow、Planning、SDK 与多 Agent，区分 Pi 已有实现与应用需要自己组织的流程。
4. **建立工程全景**：第 15～18 章，研究执行环境、Durable、安全、事件和评测。把运行结果与测试证据连接起来。

需要先看全局时，可以提前读第 13 章的装配部分，再回到第 2 章沿调用边界学习。章节末尾的继续阅读链接按编号前进。

## 每章怎样进入代码

正文中的源码摘录直接来自被核对的文件，并链接到原始实现。片段只展示局部，完整函数和调用者仍需结合说明阅读。教学 JSON 和伪代码会明确标注，不把它们描述成一次真实执行记录。

测试可以验证具体行为：模拟流适合准确观察调度与事件，真实模型评测则检查任务效果和随机性。两者能证明的范围不同。
